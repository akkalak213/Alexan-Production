## ข้อเสนอด้านความสวยงามและความน่าเชื่อถือ

- รักษาโทนสี ตัวอักษร และการแยกปุ่มหลักที่มีอยู่ เพราะสื่อบุคลิกสตูดิโอได้ชัด
- นำผลงานเด่นหนึ่งชิ้นขึ้นมาใกล้ส่วนเปิดหน้า ปัจจุบันผู้เข้าชมต้องผ่านบริการและอุปกรณ์ก่อนถึงกรณีศึกษากับภาพงานจริง
- เลือกภาพตัวแทนและจุดครอปสำหรับหน้าแรกโดยเฉพาะ โมเสกที่สุ่มตรวจมีภาพคอลลาจถูกครอปซ้ำ และช่องกว้างบางช่องเน้นส่วนชุดมากกว่าบุคคล ทำให้พลังของภาพลดลง
- เพิ่มภาพทีม/ผู้รับผิดชอบและภาพสถานที่จริงในหน้าเกี่ยวกับเรา หน้าที่ตรวจมีคำอธิบายละเอียด แต่ไม่มีภาพทีมและสถานที่นอกจากโลโก้
- ตรวจความสอดคล้องของชื่อธุรกิจ ชื่อผู้ให้บริการ เงื่อนไข และรายละเอียดบนเอกสารก่อนเผยแพร่ คำกล่าวว่ารีวิวมาจากลูกค้าจริงควรมีวิธีตรวจสอบในกระบวนการทำงานจริงด้วย รอบนี้ไม่ได้ตรวจหลักฐานหลังบ้านของแต่ละรีวิว

## สิ่งที่ทดสอบแล้วผ่าน

- หน้าแรกและหน้าหลัก `/services`, `/work`, `/rental`, `/reviews`, `/blog`, `/about`, `/contact`, `/privacy`, `/terms`, `/en` ตอบ HTTP 200
- `/robots.txt` และ `/sitemap.xml` ตอบ 200; `/th/contact?service=WEB` เปลี่ยนไป `/contact?service=WEB` โดย query อยู่ครบ; `/admin` ส่งผู้ที่ยังไม่ล็อกอินไปหน้าล็อกอิน; URL ที่ไม่มีจริงตอบ 404
- เมนูมือถือเปิดได้ ปุ่มหยุด/เล่นแอนิเมชันเปลี่ยนสถานะได้ และเปลี่ยนธีมสว่าง/มืดได้
- เลือกแพ็กเกจเว็บไซต์องค์กร 30,000 บาทแล้วฟอร์มติดต่อแสดงแพ็กเกจและราคาตรงกัน
- ค่าเช่า S5 II 1 วัน: 2,000 + VAT 140 = 2,140 บาท; 7 วันใช้ราคาสัปดาห์ 8,000 + VAT 560 = 8,560 บาท; เงินประกัน 3,000 บาทแสดงแยก ทั้งตัวเลขและจำนวนเงินเป็นคำตรงกัน
- จากเอกสาร 7 วันไปฟอร์มติดต่อ รายการกล้อง จำนวนวัน 7 และค่าเช่า 8,000 บาทส่งต่อถูกต้อง โดยฟอร์มระบุชัดว่ายังไม่รวม VAT
- ฟอร์มว่างหยุดที่ช่องชื่อที่จำเป็น ไม่ส่งคำขอจริง
- สลับภาษาในหมวดเลนส์ได้ URL `/en/rental?category=LENS` โดยยังคงตัวกรอง
- หน้ารีวิว 5 รายการมี 5 ดาว 4 รายการและ 4 ดาว 1 รายการ ค่าเฉลี่ย 4.8 ถูกต้อง
- ไม่พบ console error/warning ในเส้นทางที่อ่าน log ระหว่างทดสอบ และไม่พบภาพเสียในหน้าแรกที่ตรวจ
- HTTPS มี CSP nonce, HSTS, X-Content-Type-Options และ X-Frame-Options ใน HTTP response; นี่เป็นการตรวจส่วนหนึ่งของการตั้งค่า ไม่ใช่ penetration test
- โค้ดปัจจุบัน: `npm test` ผ่าน 111 ข้อ, `npm run typecheck` ผ่าน, `npm run lint` ผ่าน

## ขอบเขตและข้อจำกัด

ตรวจด้วย Chromium ในแอป ทั้ง 390×844 และ 1440×1000 พร้อมอ่านโค้ดและ HTTP response คะแนน PageSpeed ครอบคลุมเฉพาะหน้าแรก รอบนี้ไม่ได้ส่งข้อมูลลูกค้า รีวิว หรืออีเมลจริง ไม่ได้แก้ฐานข้อมูล ไม่ได้ทดสอบโหลดพร้อมกันหลายผู้ใช้ ไม่ได้รัน production build และไม่ได้ตรวจด้วย iPhone/Safari จริงหรือโปรแกรมอ่านหน้าจอ

working tree มีงานที่ยังไม่ commit อยู่ก่อนเริ่มตรวจ ผลทดสอบโค้ดจึงเป็นของไฟล์ปัจจุบันในเครื่อง ไม่ใช่การยืนยันว่าไฟล์ทุกส่วนตรงกับเวอร์ชัน production ทุกรายการ ประเด็นที่ระบุว่า “ยืนยันบนเว็บไซต์จริง” มีการเปิดและทดสอบบนโดเมนจริงในรอบนี้

รายงานนี้เป็นผลตรวจและแนวทางแก้ ยังไม่ได้แก้โค้ดเว็บไซต์หรือข้อมูลที่เผยแพร่
