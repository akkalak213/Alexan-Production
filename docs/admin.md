# หลังบ้าน

สิ่งที่หลังบ้านทำให้โดยไม่ต้องตั้งค่า และข้อตกลงเวลาเพิ่มฟอร์มหรือหน้าใหม่

## แดชบอร์ด: สิ่งที่ควรทำตอนนี้

ด้านบนสุดของแดชบอร์ดรวมงานค้างที่ต้องจัดการ เรียงตามความเร่ง (`src/lib/admin-tasks.ts`)

| สี | งาน | เงื่อนไข |
|---|---|---|
| แดง | คำขอที่รอตอบเกินหนึ่งวัน | สถานะใหม่ และส่งเข้ามาเกิน 24 ชั่วโมง |
| เหลือง | คำขอใหม่ที่ยังไม่ได้ติดต่อ | สถานะใหม่ ภายใน 24 ชั่วโมง |
| เหลือง | ใบเสนอราคาใกล้หมดอายุหรือหมดแล้ว | ส่งแล้ว ลูกค้ายังไม่ตอบ และยืนราคาเหลือไม่ถึงสามวัน |

| เทา | ถึงเวลาตามลูกค้า | เสนอราคาแล้วเกินเจ็ดวัน สถานะยังไม่เปลี่ยน |
| เทา | รีวิวรออนุมัติ | — |
| เทา | บทความที่ยังใช้รูปตัวอย่าง | เผยแพร่อยู่และรูปปกมาจาก picsum.photos |
| เทา | อุปกรณ์ที่ข้อมูลไม่ครบ | แสดงบนเว็บแต่ไม่มีรูปหรือไม่มีค่าเช่าต่อวัน |

มีรายการเดียวกดแล้วไปที่รายการนั้นตรง ๆ มีหลายรายการไปที่หน้ารวมที่กรองไว้แล้ว

## ฟอร์ม

ทุกฟอร์มใช้ `AdminForm` (`src/components/admin/AdminForm.tsx`) แทน `<form action={...}>`

- **บันทึกไม่ผ่าน ข้อมูลที่กรอกอยู่ครบ**
  React 19 ล้างช่องแบบ `defaultValue` ทุกช่องหลัง action ของ `<form>` ทำงานเสร็จ ไม่ว่าจะสำเร็จหรือไม่
  เดิมลืมใส่รูปปกทีเดียวต้องกรอกใหม่ทั้งหน้า `AdminForm` ส่งข้อมูลเองจึงไม่โดนล้าง
- **ตรวจก่อนส่ง** ช่องที่จำเป็น รูปที่จำเป็น (hidden input ที่มี `required`) และรูปแบบอีเมลหรือตัวเลข
  ถ้าช่องที่ผิดอยู่ในแท็บภาษาที่ซ่อนอยู่ จะสลับแท็บ เลื่อนไป และโฟกัสให้ ช่องรูปขึ้นข้อความตรงช่อง
- **ข้อผิดพลาดจาก server** คืน `field` มาใน state ได้ ฟอร์มจะพาไปที่ช่องนั้นเหมือนกัน
  เช่น `{ status: 'error', message: 'ต้องใส่รูปปกก่อนบันทึก', field: 'coverImage' }`
- **แถบ "มีการแก้ไขที่ยังไม่ได้บันทึก"** ติดล่างจอเมื่อมีการแก้ค้าง (ฟอร์มที่ส่ง `saveLabel`)
- **Ctrl + S** (Mac: ⌘ + S) บันทึกฟอร์มที่กำลังพิมพ์อยู่ หรือฟอร์มเดียวที่มีการแก้ค้าง

"แก้ค้าง" เทียบจากค่าที่จะถูกส่งจริงกับตอนเปิดหน้าหรือตอนบันทึกล่าสุด (`src/lib/form-snapshot.ts`)
พิมพ์แล้วลบกลับเป็นค่าเดิมไม่นับ สลับลำดับรูปหรือเอารูปออกนับ

### เพิ่มฟอร์มใหม่

```tsx
const [state, formAction, isPending] = useActionState(saveSomething, initialAdminState)

<AdminForm action={formAction} state={state} isPending={isPending} guardLabel="สิ่งที่แก้" saveLabel="บันทึก">
  ...
</AdminForm>
```

- `guardLabel` ใส่เมื่อควรเตือนก่อนออกจากหน้า ข้อความในกล่องเตือนคือ "คุณกำลังแก้ไข{guardLabel}ค้างอยู่"
- `saveLabel` ใส่กับฟอร์มยาวที่ปุ่มบันทึกมักอยู่นอกจอ
- `resetOnSuccess` สำหรับฟอร์มที่ต้องว่างหลังบันทึก เช่นโน้ต
- ปุ่มลบให้อยู่ในฟอร์มแยกของตัวเองเหมือนเดิม ไม่ต้องใช้ `AdminForm`

## เตือนก่อนออกจากหน้า

`LeaveGuard` (`src/components/admin/LeaveGuard.tsx`) วางไว้ที่ `AdminShell` ที่เดียว ทำงานกับทุกฟอร์มที่มี `guardLabel`

| ออกจากหน้าด้วย | สิ่งที่เกิดขึ้น |
|---|---|
| คลิกลิงก์ในหลังบ้าน | กล่อง "ออกจากหน้านี้ใช่ไหม" พร้อมปุ่มอยู่ต่อ / บันทึกก่อน / ออกโดยไม่บันทึก |
| ปุ่มย้อนกลับหรือปัดย้อนบนมือถือ | กล่องเดียวกัน หน้าไม่เปลี่ยนจนกว่าจะกดออก |
| ออกจากระบบ | กล่องเดียวกัน (ฟอร์มที่ติด `data-leave-guard`) |
| ปิดแท็บ รีเฟรช พิมพ์ URL ใหม่ | กล่องยืนยันของเบราว์เซอร์ ข้อความเปลี่ยนไม่ได้ |

ลิงก์ที่เปิดแท็บใหม่ (`target="_blank"`) ไม่ถาม เพราะหน้านี้ยังอยู่

ปุ่มย้อนกลับยกเลิกตรง ๆ ไม่ได้ ตอนเริ่มแก้จึงวางช่องกันไว้ในประวัติหนึ่งช่อง (URL เดิม)
บันทึกเรียบร้อยแล้วกดย้อนกลับครั้งเดียวก็ออกได้ตามปกติ ช่องกันจะพาย้อนต่อให้เอง

## ฟอร์มอุปกรณ์

ช่องค่าเช่าคำนวณให้ดูระหว่างพิมพ์ (`RateHint`): เช่า 7 วันแบบรายวันเป็นเท่าไร เรตสัปดาห์ลดกี่เปอร์เซ็นต์
และเตือนเมื่อเรตสัปดาห์ไม่ถูกกว่ารายวัน 7 วัน ซึ่งระบบจะไม่ใช้เรตนั้นเลย

## ลบรีวิวและใบเสนอราคา

ทั้งสองอย่างลบถาวร กู้คืนไม่ได้ ปุ่มลบต้องกดสองจังหวะ (กดครั้งแรกแค่ถาม)

- **รีวิว** ปุ่มลบอยู่บนการ์ดรีวิวทุกใบในหน้ารีวิว ต่างจาก "ปฏิเสธ" ที่ยังเก็บรีวิวไว้ในแท็บปฏิเสธแล้ว
  รีวิวที่เผยแพร่อยู่หายจากหน้าเว็บทันที
- **ใบเสนอราคา** ลบได้จากหน้ารายการ หรือกล่องลบท้ายหน้ารายละเอียด
  - ใบที่เคยส่งอีเมลให้ลูกค้าแล้ว เลขที่จะถูกจดไว้ (SiteSetting `documentNumbers`) ใบใหม่จะไม่ได้เลขซ้ำกับเอกสารที่ลูกค้าถืออยู่
  - ใบที่ไม่เคยส่ง เลขที่ว่างให้ใบถัดไปใช้ได้
  - ถ้าเป็นใบสุดท้ายของคำขอ คำขอที่เป็น "เสนอราคาแล้ว" จะกลับเป็น "ติดต่อแล้ว"

## ฟอร์มรีวิวบนหน้าเว็บ

บังคับกรอกชื่อ บริการที่ใช้ และคำรีวิว (อย่างน้อย 20 ตัวอักษร) ตรวจทั้งในเบราว์เซอร์และฝั่ง server
ช่องคำรีวิวนับตัวอักษรให้ระหว่างพิมพ์ ส่งไม่ผ่านข้อความที่พิมพ์ไว้ยังอยู่ครบ
