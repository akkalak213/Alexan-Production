# หน้าแรกและหน้าตาหน้าสาธารณะ

หน้าแรกเล่าเรื่องตามลำดับที่ลูกค้าคิด และ **ของแต่ละชิ้นขึ้นแค่ที่เดียว**
ภาพไม่ซ้ำกันทั้งหน้า และแต่ละส่วนมีรูปทรงของตัวเอง ไม่ใช่การ์ดชุดเดียวซ้ำทั้งหน้า

โทนสีกระดาษอุ่นกับทองแดง ฟอนต์ และโลโก้ใช้ชุดเดิม หัวเรื่องหลักแก้ได้จากหน้าตั้งค่าในหลังบ้าน

## ลำดับของหน้าแรก

| ส่วน | รูปทรง | ตอบคำถาม |
|---|---|---|
| เปิดหน้า | ห้องมืดเสมอ หัวเรื่องใหญ่ ฉากสตูดิโอที่ขยับได้เป็นพื้นห้อง | เราคือใคร |
| บริการ | รายการราคาเป็นแถว แบ่งกลุ่มเว็บ/แอป กับภาพ/วิดีโอ | ทำอะไรได้ เริ่มต้นเท่าไหร่ |
| สตูดิโอและเช่า | ชั้นวางอุปกรณ์เลื่อนแนวนอน + แถบสิ่งที่มีในสตูดิโอ | มีของให้เช่าไหม ราคาเท่าไหร่ |
| งานดิจิทัลล่าสุด | หน้าต่างเบราว์เซอร์ สลับภาพหน้าจอจริงได้ | ทำเว็บได้จริงไหม |
| งานถ่ายภาพ | โมเสกเจ็ดภาพบนพื้นมืด | ถ่ายภาพได้จริงไหม |
| เริ่มงานกับเรา | เส้นเวลาสามขั้นไม่มีกรอบ + คำถามที่พบบ่อย | ต้องเริ่มยังไง |
| รีวิว | ขึ้นเฉพาะเมื่อมีรีวิวที่อนุมัติแล้ว | คนอื่นว่ายังไง |
| ชวนคุย | แถบสีทองแดง | ติดต่อทางไหน |

ส่วนเช่าอยู่ต่อจากรายการบริการทันที คนที่มาหาอุปกรณ์เห็นราคาเช่าโดยไม่ต้องเลื่อนผ่านผลงานก่อน
สองส่วนนี้พื้นสีเดียวกัน จึงคั่นด้วยเส้นบนของส่วนเช่า

ฉากสตูดิโออยู่ที่ส่วนเปิดหน้าที่เดียว บริการสตูดิโอไม่อยู่ในรายการราคา ไปอยู่ในส่วนเช่าที่เกี่ยวข้องจริง

## ข้อมูลมาจากไหน

Query ของหน้าแรกอยู่ใน `src/server/queries.ts` (`getHomeServices` `getEquipment` `getHomeDigitalCase` `getHomePhotos`)
ทุกตัวถูกแคชและล้างทันทีเมื่อหลังบ้านบันทึก (ดู `docs/performance.md`)

- **กลุ่มบริการ** ตาม `DIGITAL` กับ `VISUAL` ใน `src/app/[locale]/page.tsx`
  (`WEB` `WEB_APP` `MOBILE_APP` / `PHOTOGRAPHY` `VIDEO`) ส่วน `STUDIO` ไปอยู่ส่วนเช่า
  **ถ้าเพิ่ม `ServiceCategory` ใหม่ต้องเพิ่มเข้ากลุ่มด้วย** ไม่งั้นบริการนั้นจะไม่ขึ้นหน้าแรก
- **ราคาเริ่มต้น** มาจากแพ็กเกจที่ `priceFrom` ต่ำสุดของบริการนั้น พร้อมหน่วย (ต่อโปรเจกต์ ต่อครึ่งวัน ต่อชั่วโมง)
  แพ็กเกจแบบ `CUSTOM` หรือไม่มีราคาแสดงเป็น "ประเมินตามขอบเขตงาน" บริการที่ไม่มีแพ็กเกจเลยไม่แสดงราคา
- **ชั้นวางอุปกรณ์** โชว์เฉพาะของที่สถานะว่าง ราคาที่เห็นจึงจองได้จริง ของที่ไม่ว่างยังดูได้ในหน้าเช่า
  **สิ่งที่มีในสตูดิโอ** คือจุดเด่นของบริการ `STUDIO`
- **งานดิจิทัล** คือผลงานหมวดเว็บที่เผยแพร่แล้วหนึ่งชิ้น ผลงานเด่นมาก่อน
  ภาพหน้าจอมาจากภาพเพิ่มเติมของผลงาน (สูงสุดหกภาพ) ถ้าไม่มีใช้รูปปก ชื่อโดเมนบนแถบเบราว์เซอร์มาจาก `liveUrl`
- **โมเสก** หยิบภาพกระจายให้ทั่วแต่ละชุดจากงานหมวดภาพสูงสุดสามงาน แล้วสลับงานละภาพจนครบเจ็ด
  ภาพงานถ่ายเรียงตามเวลา ช่วงต้นชุดมักเป็นมุมเดียวกันหลายช็อต หยิบติดกันจะได้ภาพที่แทบเหมือนกัน
  อยากเปลี่ยนภาพที่ขึ้นหน้าแรก ให้จัดลำดับภาพของผลงานในหลังบ้าน ถ้ามีภาพไม่ถึงสามภาพ ส่วนนี้จะซ่อน

## มือถือ

- **ฉากสตูดิโอ** ไม่ย่อทั้งฉากให้พอดีจอ (จะเล็กจนดูไม่ออก) วางกว้าง 740px แล้วเลื่อนกรอบให้เห็นช่างภาพถึงโต๊ะสินค้า
- **รายการบริการ** ราคาย้ายลงไปอยู่ใต้ชื่อบริการ แถวทั้งแถวเป็นพื้นที่กด
- **ชั้นวางอุปกรณ์** ปัดด้วยนิ้ว ใบถัดไปโผล่ที่ขอบจอบอกว่าปัดต่อได้ ปุ่มซ้ายขวามีเฉพาะอุปกรณ์ที่มีเมาส์
- **โมเสก** สองคอลัมน์ เจ็ดช่องเต็มพอดี คำบรรยายบนภาพขึ้นเฉพาะตอนชี้ด้วยเมาส์
- **หัวเรื่อง** จอตั้งแต่ 640px ตัดบรรทัดได้เฉพาะตรงช่องว่างที่เขียนไว้ในหน้าตั้งค่า
  ภาษาไทยไม่เว้นวรรคระหว่างคำ ไม่งั้นเบราว์เซอร์ตัดกลางวลี จอแคบกว่านั้นตัดตามปกติเพื่อไม่ให้ล้นจอ
  ช่วงวลีต้องสืบ `line-height` จากหัวเรื่อง เพราะ `:lang(th)` ใน globals.css ตั้ง 1.75 ให้ทุกองค์ประกอบโดยตรง

## การเคลื่อนไหว

- **ฉากสตูดิโอ** เคยถูกปิดแอนิเมชันทั้งฉากด้วย `animation: none !important` เพื่อเลี่ยงการทำปุ่มหยุด
  ตอนนี้เปิดกลับแล้ว หยุดเองเมื่อพ้นจอเกิน 160px และมีปุ่มหยุด/เล่นตาม WCAG 2.2.2
  ระหว่างหยุดจะซ่อนแสงแฟลช กันจอสว่างค้างถ้าหยุดตรงจังหวะที่แฟลชยิง
- ลำแสงกับโคมอยู่ในกลุ่มที่มีฟิลเตอร์เบลอ จึงให้ค่าโปร่งใสขยับเป็นขั้น (`steps(40)`) วาดใหม่ราว 6 ครั้งต่อวินาทีแทน 60
- แก้บัคเดิม: คนที่ตั้งค่าลดการเคลื่อนไหวเคยเห็นแสงแฟลชสว่างค้างถาวร
- **HomeMotion** ติด `data-enter="pending"` เฉพาะก้อนที่ยังอยู่ใต้จอตอนสคริปต์พร้อม ก้อนที่อยู่บนจอแล้วไม่ถูกซ่อน
- **ตอนชี้** หน้าจอในหน้าต่างเบราว์เซอร์ค่อย ๆ เลื่อนลงจนสุดหน้า ภาพถ่ายกับรูปอุปกรณ์ซูมเล็กน้อย
- `prefers-reduced-motion: reduce` ปิดทุกอย่างข้างบน รวมถึงซ่อนปุ่มหยุด/เล่นเพราะไม่มีอะไรให้หยุด

## ขนาดตัวอักษร

เนื้อความไม่ต่ำกว่า 15px ข้อความประกอบไม่ต่ำกว่า 13px ภาษาไทยที่มีสระบนล่างต่ำกว่านี้อ่านยากบนมือถือ

## ดูตัวอย่างแบบ production บนเครื่อง

หลัง `npm run build` ให้รัน `npm run start -- --hostname localhost` แล้วเปิด `http://localhost:3000`
บน Windows กับ Next รุ่นนี้ ถ้าผูกกับ `127.0.0.1` หน้าไทยจะ redirect วนตัวเอง ผูกกับ `localhost` แล้วได้ 200 ปกติ
